# Social Network

Пет-проект социальной сети с общим чатом, JWT-аутентификацией и полным циклом контейнеризации и развёртывания.

## Технологии

### Backend

* **FastAPI** — REST API
* **SQLAlchemy** — работа с базой данных
* **SQLite** — база данных
* **JWT** — аутентификация и авторизация

### Frontend

* **React** — пользовательский интерфейс
* **React Router** — маршрутизация
* **React Bootstrap** — UI-компоненты
* **Axios** — HTTP-запросы к API

### DevOps / Инфраструктура

* **Docker** + **Docker Compose** — контейнеризация и оркестрация сервисов
* **Nginx** — reverse proxy и раздача статики
* **Multi-stage Docker builds** — оптимизация Docker-образов
* **Dev / Prod конфигурации** — разделение окружений
* **Environment variables** — управление конфигурацией и секретами
* **PostgreSQL-ready** — возможность перехода на PostgreSQL для production

## DevOps-составляющая

Проект полностью контейнеризирован и состоит из нескольких изолированных сервисов.

### Контейнеризация

Каждый основной компонент приложения запускается в отдельном Docker-контейнере:

* Backend
* Frontend
* Nginx

### Оркестрация

**Docker Compose** отвечает за:

* запуск и остановку сервисов;
* создание общей сети;
* управление зависимостями между контейнерами;
* подключение volumes;
* передачу переменных окружения.

### Сеть

Для взаимодействия сервисов используется отдельная Docker `bridge`-сеть.

### Reverse Proxy

**Nginx** выступает в роли reverse proxy и маршрутизирует запросы между frontend и backend API.

### Конфигурация и секреты

Конфигурация приложения вынесена в переменные окружения.

Секретные данные не должны храниться непосредственно в исходном коде или попадать в Git-репозиторий.

Для настройки используется файл `.env` на основе `.env.example`.

### Production-ready подход

Проект использует:

* multi-stage Docker-сборки;
* отдельные конфигурации для окружений;
* изолированные контейнеры;
* reverse proxy;
* environment variables;
* архитектуру, позволяющую перейти с SQLite на PostgreSQL.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <URL>
cd social-network
```

### 2. Создание `.env`

```bash
cp .env.example .env
```

При необходимости отредактируйте значения переменных окружения в `.env`.

### 3. Запуск Docker Compose

```bash
docker compose up -d --build
```

После успешного запуска контейнеров приложение будет доступно по адресу:

**http://localhost:3000**

## Полезные команды Docker

Посмотреть запущенные контейнеры:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f
```

Остановить приложение:

```bash
docker compose down
```

Пересобрать и запустить контейнеры:

```bash

```
